User guide
==========

The following tutorials allow you to get started and explore the possibilities offered
by this package. They are `marimo <https://marimo.io>`_ notebooks (plain python files)
located in the ``examples`` directory of the repository: open them with
``marimo edit <notebook>.py`` or run them as scripts with ``python <notebook>.py``.

.. toctree::
   :maxdepth: 2

   2D toy example <notebooks/2d_toy_example>
   Pumping history identification (linear) <notebooks/pumping_linear_inversion>
   Pumping history identification (nonlinear) <notebooks/pumping_nonlinear_inversion>

Other examples rely on external simulators (MODFLOW, STWAVE, CrunchTope, TOUGH,
MARE2DEM, AdH, E4D, FEniCS) that must be installed separately. See
``examples/README.md``.
